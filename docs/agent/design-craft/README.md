# Interface Craft References

Use these notes with `docs/agent/ui-rubric.md`. They turn small visual details
into repeatable implementation rules.

- [Image outlines](image-outlines.md): frame media with a faint inset edge.
- [Optical alignment](optical-alignment.md): align visual weight, not only boxes.
- [Nested border radius](nested-border-radius.md): keep nested curves concentric.
- [Hover restraint](hover-restraint.md): keep frequent interactions immediate.

These are defaults, not substitutes for checking the rendered interface in
light mode, dark mode, touch layouts, and keyboard navigation.
